# Leone Lens — The 8-Step Build Order

1. Enable embedded first: turn on prebuilt Fusion agents and configure them to your policies. This is the lowest effort in the ROI equation.
2. Pick one cross-functional outcome with a named owner and a measurable baseline.
3. Set the envelope before autonomy: objectives, SOP, permissions, risk thresholds, approvals, escalations. Then set the dial to assist or research.
4. Extend in Agent Studio, natively. Reuse Marketplace and partner agents before bespoke builds.
5. Separate reasoning from execution for volume work. Consider Fusion Claw only when the work is specialist, long-running, or simulation and optimisation heavy.
6. Earn governed action with receipts: review Outcome Receipts, accuracy, and cost per outcome. Use simulation and budgets. Downgrade models where accuracy holds. Only then widen autonomy.
7. Use FSCR patterns for implementation and expansion: agents operate, the registry is the authority, experts review and approve.
8. Scale by outcome portfolio, learning across runs — not by agent count.
