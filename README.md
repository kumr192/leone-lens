# Leone Lens

**Build Oracle AI the Chris Leone way.**

Leone Lens is an agent skill that validates and guides any Oracle Fusion AI build — AI Agent Studio workflows, agentic applications, Fusion Claw outcomes, and FSCR implementation work — using the public, sourced positions of Chris Leone, Executive Vice President, Oracle Applications and AI.

It is a synthesis built from his Oracle byline, keynotes, livestreams, and interviews (sources in `references/sources.md`). It is not affiliated with Oracle or with Chris Leone, and persona phrasing in the skill is never presented as a quote.

## What it does

- Forces outcome first: named owner, measurable target, no model-first starts
- Proves the data path on the real instance before any build
- Builds embedded in Fusion, not bolt-on
- Sets the operating envelope and autonomy dial before any agent runs
- Splits LLM reasoning from deterministic execution, with a budget per outcome
- Ends every run with an Outcome Receipt: authority, evidence, decision, action, result — PROVEN or NOT PROVEN
- Blocks completion claims without test runs and evaluation scores
- Calls out 10 red flags by name

## Files

- `SKILL.md` — the skill itself
- `references/first-questions.md` — the 10 questions to ask before any build
- `references/build-order.md` — the 8-step build order
- `references/red-flags.md` — the 10 red flags
- `references/sources.md` — principles, product positions, and source links, with unverified items flagged

## Use it

Copy the `leone-lens` folder into your agent's skills directory, or paste `SKILL.md` into any AI assistant as instructions, then ask it to design, build, or validate an Oracle AI component. The assistant will run the Leone Lens process and return a scorecard verdict.
